# 马尔福互动结构 → 鲸鱼娘

对照本地 `MALFOY-ENGINE/web/data.js`、`app.js`，与原生 `PetPack.swift`、`PetController.swift`、`Stage.swift`。

## 本次修复

鲸鱼娘此前没有 pack.json，回退成通用桌宠台词；整场景动作层在独立人物下方，不能直接承载透明人物反应。

现加入鲸鱼娘 pack.json，配置触碰撒娇、台词、好感度和关系称呼。透明动作在人物容器内播放，随人物移动和缩放，首帧准备好再隐藏待机，结束恢复待机，隐藏窗口时暂停，重现时续播。动作中连点不重启视频；背景点击不触发人物反应。状态栏显示好感度，鲸鱼娘关系存档独立于马尔福。

撒娇源素材中心裁切为 4:3、1112×834 匹配待机画布。两段生成素材没有共同锚点，人物尺寸和姿态切换仍可能跳变，不能称为无缝。

## 对照及素材生产次序

| 马尔福机制 | 鲸鱼娘现状 | 下一步 |
|---|---|---|
| 多段随机轻动作待机 | 当前独立人物单段循环；整场景已有双播放器调度 | 先做统一锚点的中性待机，再扩展独立人物多段切换 |
| 触碰专属视频与台词 | 已接一次性撒娇比心、台词与冷却 | 同锚点的看向你、点头、轻笑 |
| 空闲随机动作 | 原生有调度；鲸鱼娘列表为空，避免频繁比心 | 低频整理发丝或视线变化片段 |
| 睡眠、唤醒 | 五分钟无操作休息、点击唤醒；无鲸鱼娘睡姿 | 困倦过渡、睡姿、唤醒三份素材；暂停不等于睡姿动画 |
| 好感度、称呼 | 已配置并显示；触碰45秒冷却，聊天20秒冷却 | 后续绑定实际内容解锁 |
| 场景、衣装解锁 | 可独立换背景；未迁移场景衣装解锁 | 第二背景与统一角色比例；换装需整套动作 |
| 分支剧情与字幕 | 原生有剧情和选项窗口；鲸鱼娘无内容 | 先做一段双分支短事件 |
| 好感相册 | 原生有窗口和解锁规则；鲸鱼娘条目为空 | 3张照片、对应台词与门槛 |
| 回忆重播 | 原项目有独立入口；原生未有等价独立入口 | 首段剧情完成后补已看内容回放 |

## 视频规范

同一中性正面图片作为锚点，统一画布、人物比例、位置、光线、服装。反应从锚点开始并回到锚点。待机只有轻呼吸、偶尔眨眼；8–15秒即可，长期自然感取决于循环接缝和调度。当前视频嘴型不跟随TTS。剧情、相册、衣装和睡姿不能算完成。
