# 澜 · 二十六景

使用内置 `image_gen` 生成，角色参考为 `../whale-girl/three-view-greenscreen.png`。目录名沿用任务开始日，生成于 2026-10-30。

- `originals/`：26 张原始 PNG，保留生成尺寸，不放大伪称 4K。
- `generation.json`：逐张主题、提示词、角色约束、来源及好感度阈值。
- `../whale-video-test/album-*.jpg`：92 质量 JPEG 运行副本，从原图派生；应用只打包这些副本。

在应用菜单或人物右键菜单打开「相册…」。前 4 张初始开放，其余在好感度 8–90 逐步解锁；点击开放的卡片可看大图并保存壁纸。项目里的原图始终可以全部查看。不会修改个人好感度或聊天数据。

## 重建与检查

在 `desktop-companion` 运行：

```bash
python3 scripts/import-whale-album.py
python3 scripts/pack-assets.py assets/whale-video-test
bash scripts/check-whale-album.sh
bash scripts/build-whale-video.sh
```

这批是静态收藏壁纸。舞蹈、亲亲、换衣等名称描述画面主题，当前没有新增相应视频或桌宠动作。人脸和服装细节由生成模型绘制，不能视为逐像素一致。
