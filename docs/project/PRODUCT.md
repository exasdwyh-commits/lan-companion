# 产品定义与制作方向

依据：2026-10-30 双世界方向；2026-11-01 用户确认共创型伙伴、可植入剧情、首版非商业与未来三模式愿景。实现情况另看 [STATUS.md](STATUS.md)。战略与验收草案见 [COMPANION-STRATEGY-DRAFT.md](COMPANION-STRATEGY-DRAFT.md)。

## 目标

macOS 共创型智能陪伴：同一角色跨越她的世界与用户桌面，有稳定性格、自己的偏好与边界；与用户作为朋友一起读书、写作、延展剧情，记得经过确认的共同经历，也能在授权下通过 agent 协助工作。不是一味顺从的主仆关系。

首版先做非商业版本，免费、非营利、拟开源；先验证持续使用价值。暂不建设付费层、商城、复杂数值系统或世界模型基础设施。非商业不等于素材可随意再分发，开源范围另行核准。

## 三板块结构（2026-11-01 用户定版）

主场景与开发顺序按以下三板块组织；同一时间仍只有一个交互舞台，切换不重置对话与任务。

| 板块 | 内容 | 阶段 |
|---|---|---|
| **① 她的小屋（主场景）** | `web/moli-room/` 底座上的 3D 小房间：澜按真实时间作息生活、看书/游戏/听歌/睡觉，猫与扫地机、环境音、真实天气昼夜；后续替换澜的 3D 形象并做海边主题化 | **当前主线** |
| **② 桌面（用户桌面）** | 透明桌面上的 Q 版神识：漫游、点击、聊天、工作、读书、唱歌入口 | 二阶段，能力保持已验收基线 |
| **③ 真人视频（她的世界·旧马尔福线）** | 640×360 真人视频窗：待机/触摸/趴屏/睡眠/月夜祈愿、相册、图文剧情 | 三阶段，功能保持现状不扩张，待小屋与桌面稳定后再迭代 |

- 小屋是澜的"家"与默认驻留场景；桌面是从家召唤出来的随身形态；真人视频是后续的沉浸呈现层。
- 三板块共享同一身份、记忆、关系与音频仲裁；不存在三套人格或三份记忆。
- 原「双世界」文档口径（world=真人视频为默认）由本节取代；已建成的真人视频能力不删除、不回退，只是排期后移。
- 优先级含义：新功能默认先服务小屋（含 3D 角色落地、主题化、与聊天/记忆/工作的接线），其次桌面体验，真人视频板块只修缺陷不加新范围。

## 两种形态（历史口径，映射到三板块）

| 她的世界（→ 板块③ 真人视频） | 用户桌面（→ 板块②） |
|---|---|
| 年轻成年、真人写实鲸鱼娘；蓝长发、鳍耳、蓝白银服装 | 蓝长发、鳍耳、鲸尾、蓝白女仆裙的 Q 版 2D 小人（板块① 小屋内为 3D 形象） |
| 常作动态背景，主动进入时看剧情、相册、视频互动 | 常用入口：自由活动、点击、聊天、工作、读书、唱歌 |
| Qwen3-TTS 清冷音色 | Qwen3-TTS 活泼音色 |
| 场景、剧情和状态可以逐步扩展 | 有真实工作进度与可打开的结果 |

现阶段可交付的差异化是**真能读本地书（朗读、续读、讨论）＋同一伙伴在两个空间切换**；真实书籍听感和原生切换仍按 STATUS/TASKS 验收，不因定位明确而标完成。

未来候选为第三种**实时真人互动模式**：若 Vidu S2 或同类技术在延迟、角色一致性、连续交互、成本与授权上通过实测，可提供更接近真人相处的视觉体验与关系成长玩法。它是同一角色的第三种呈现，不建立第二套记忆或独立人格；当前视频世界不等于实时数字人。首版不以其为依赖，也不宣传三模式已交付。

真人形象保持写实，Q 版明确允许卡通化；旧“所有形态都不能二次元”的规则不覆盖桌面。

Q 版比例以用户两张参考为准：约两头身、圆润宽脸、短手短腿、蓬松宽轮廓、明显鲸尾。用户已否定 v1 瘦长身体与长腿方向；后续素材不得沿用该比例。用户随后已接受圆润 v2 形象，当前重点是根据情境丰富表情、姿态和道具；已有首批 16 幅表演图，接口见 [CHIBI-MOTION](CHIBI-MOTION.md)。

## 身份与故事

- 当前已定：双空间里都是**同一个澜**，共享角色、记忆、关系、阅读和任务进度。旧“神识化身”属于轮回瓶叙事的解释方式，是否保留尚待设计；不另设守护精灵或第二人格。
- **澜就是“小肥鱼”**，不是另一位主角。她是修仙界弱小门派的普通小透明，受强势宗门与天骄压制，开局**被打回原形，从头开始**；轮回瓶设定撤销。之后是重新修炼、成长反击，还是躺平成为“大肥鱼”，由她自己的行动与你们的互动逐步形成，不预设胜负或终点。用户是她结契的异界伙伴，不是主人；她做关键选择，也承担后果。克劳德、柴德吉皮提、珍穆耐目前只是用户举的天骄称谓，公开角色/IP 设定待另议。
- 旧“突破失败、遭人暗害、进入轮回瓶；本体修养时神识来到桌面”及其对应分镜**不再是现行剧情依据**。双空间与同一身份仍保留；被打回原形如何联系用户、两个形态为何切换，尚待后续叙事设计，不能把旧机制偷渡回来。
- 澜可以从标准化剧本底子出发，**以自己的视角讲述经历、创作小说或剧本，让剧情随她和用户的选择发展**。底子只固定身份、冲突、世界规则和重要边界；具体章节、对白、敌方动机、胜负与结局不预设。她的创作草稿与角色经历分开记录，经用户确认的共同创作才成为作品正典；不能把编出的情节自动写成现实共同记忆。
- 目前这些都是方向，非已实现的动态叙事功能。现有「潮汐初遇」只是图文剧样板，不代表新修仙线第一章已经制作。
- 产品暂称“澜”，现有包内“深蓝”等命名另行统一，不为改名复制工程。
- 默认关系是**共创型朋友**：澜可以主动提出故事、对设定发表不同意见或礼貌拒绝；用户可拒绝提议，不能以惩罚、催回复或排他话术换取留存。用户拥有对自己文件、隐私、作品定稿和持久世界改动的最终决定权。
- 剧情可植入共同创作：从“被打回原形”出发，澜的修炼、休息和共创经历经明确选择进入故事与场景；没有单一的苦修正确路线或躺平失败结局。即兴虚构不自动成为真实经历或已定的剧情正典。现有「潮汐初遇」仍是样板，不是已实现的动态剧情系统。

## 窗口与对话入口

| 状态 | 行为 | 验收重点 |
|---|---|---|
| hidden / dormant | 隐藏并暂停角色，保留悬浮聊天入口 | 恢复同形态窗口时继续播放 |
| wallpaper | 托盘显式选择的非交互背景 | 不抢焦点、不挡桌面 |
| world | 默认 640×360 真人世界，可拖动/等比缩放，禁止原生全屏 | 正常/触摸/趴屏/睡眠/唤醒/暂停；相册/图文剧情入口已接，内容一致性与原生全流程待验 |
| desktop | 透明桌面上的 Q 版神识 | 小巧可点、空白穿透、任务反馈清楚 |

桌宠默认 180 CSS px 高，托盘「桌宠大小」可选 140/180/220，两个轴始终等比；不再随大屏自动放大。当前档位在本次运行中跨形态保留，重启回到标准。

独立 64px 悬浮聊天图标，展开可打字或录音 4 秒转成草稿，确认后发送；切换世界不关闭聊天。角色舞台统一播放回复，聊天窗不重复出声。`⌥⌘J` 展开/收起。

同一时间最多一个交互舞台；切换不能重置对话与任务，不能重复播放语音或执行工作。

## 简单成长

1. 稳定人格：核心价值观与习惯不乱变，双音色只改变表达方式。**自主性通过行动表现**：自己选书、暂缓修炼、惦记未完章节并能解释原因，不靠对白宣称。
2. 共同记忆：偏好、约定、重要经历、阅读进度；用户可纠正和删除。
3. 缓慢变化：信任、兴趣、亲密表达，由真实共同经历推动。
4. 剧情与关系有关联，但不把所有活动都做成刷好感任务。**确认分级**：日常活动免确认；她的邀请轻确认（选/改/拒一次）；作品正典、持久世界改动、对外发布强确认＋可撤销。相处不能变成连续审批。
5. 角色设定、确认的共同经历、用户个人事实与作品/世界正典分开；持久写入需确认并能查看、纠正、撤销或导出。此条是目标契约，不表示现有记忆模块已经全部支持。

## 非商业版本逐步形成的闭环（不代表当前均已完成）

- 双世界进入、召唤、返回，共享记忆和清冷/活泼音色。
- 现有鲸鱼视频、相册、图文剧情、歌曲在主线有可用入口。
- Q 版待机、走路、坐下/休息、聊天、思考、任务完成；单图平移不能标成走路动画完成。
- 读书：本地文本、进度、暂停继续、朗读与讨论，重启能续读。
- 工作：调用已有 agent 适配器，能看到运行/失败/取消及真实产物。
- 简单记忆管理与关系连续性，不把生成的虚构经历存成用户事实。
- 共创最小闭环：澜提出剧情方向或小屋改动 → 用户选/改/拒绝 → 双方写一段作品或预览变更 → 用户确认才保存正典/世界状态 → 切换形态与重启后能准确接续、撤销和导出。此为后续阶段目标，不列作当前现成功能。

## 本版边界

Live2D、实时口型、麦克风、屏幕视觉、多显示器可后续扩展；已存在接口保留，未验收不宣传完整能力。唱歌先保留播放、停止与歌词；作曲编曲、节奏和音色质量另列任务。首版不训练大模型，不要求实时生成真人视频。
