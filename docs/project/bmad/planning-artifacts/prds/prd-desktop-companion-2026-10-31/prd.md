# PRD: 读书按章跳转

## 0. Document Purpose

给「深蓝」桌宠的读书功能补上按章导航。读者打开一本二十章的小说时，目前只能靠「下一段」逐段前进，无法直接回到某一章。本 PRD 只覆盖章节识别与跳转，不涉及朗读合成、音色或播放仲裁。

## 1. Vision

一本长篇小说的自然导航单位是「章」，不是「段」。当前实现把书切成了几百个段落，读者想重读第三章只能连点几十次。补上章节层之后，读者看到的是一张目录，点一下就回到那一章的第一句。

## 2. Target User

单个使用者：本书作者本人（Kou），中文长篇小说为主，习惯从上次进度续读，也会跳回特定章节重听。

### 2.1 Jobs To Be Done

- 我想知道这本书一共有几章，现在读到第几章。
- 我想直接跳到某一章重听，而不是一段段点过去。
- 我导入的书如果根本没有章节结构，我不希望界面上多出一块空目录。

### 2.2 Key User Journeys

**UJ-1 续读并跳章**：Kou 导入《潮汐》共 18 章，上次读到第 7 章第 3 段。打开面板看到「第 7 章 / 共 18 章」，点目录里的第 12 章，朗读从第 12 章第一段开始。

**UJ-2 无章节的书**：Kou 导入一篇散文，正文没有任何章节标题。面板不出现目录控件，进度仍显示「第 N / M 段」，行为与现在完全一致。

## 3. Glossary

- **章（chapter）**：正文中独占一行的章节标题所标记的区段。识别到标题的那一段即为该章首段。
- **章首段（startParagraph）**：该章标题所在的段落索引。
- **降级（fallback）**：识别不到任何章节时，不提供章节能力，退回段落级导航。

## 4. Features

### 4.1 章节识别

**FR-1** 解析朗读稿时识别章节标题。命中规则：独占一行，且匹配 `第<数字或中文数字><章节卷回部篇>`，可选后接标题文字（如「第一章 潮汐」）；同时兼容 `Chapter <n>`、`Prologue`、`Epilogue`。

**FR-2** 每个段落记录其所属章节序号；章首段记为 0 距离，后续段落继承该章。

**FR-3** 识别结果随书持久化到 `reading.json`，重启后无需重新解析。

### 4.2 章节导航

**FR-4** 状态快照暴露 `chapters: [{index, title, startParagraph}]` 与当前 `chapter` 序号；无章节时 `chapters` 为空数组。

**FR-5** `jump` 操作支持 `{chapter: n}`：跳到第 n 章首段，并停止当前播放。越界或书无章节时明确报错，不静默失败。

**FR-6** 面板显示当前章位置（「第 N 章 / 共 M 章」）与可点的章目录；点击即跳转。

**FR-7** 无章节的书不渲染目录控件，进度文案保持段落级，不得出现空目录或「第 0 章」。

## 5. Non-Goals (Explicit)

- 不做「卷 → 章」的嵌套树，只做平铺一层。
- 不解析 EPUB 的 `toc.ncx` / `nav.xhtml` 目录元数据，只从正文识别。
- 不做章节内的二级跳转（段落级导航已存在）。
- 不改动朗读合成、音色分配、播放仲裁。

## 6. MVP Scope

### 6.1 In Scope

FR-1 至 FR-7 全部。纯文本（TXT/MD）与 EPUB 提取出的正文都走同一条识别路径。

### 6.2 Out of Scope for MVP

自定义章节规则、目录折叠展开、章节字数统计、按章导出音频。

## 7. Success Metrics

- 一本 18 章的中文小说，章节识别覆盖率 ≥ 90%，且不把正文句子误判成标题。
- 按章跳转后，播放从该章首段开始，段落索引与 `startParagraph` 一致。
- 无章节文本导入后，面板不出现目录控件（回归断言）。

## 8. Open Questions

- 章节标题的判定阈值：只认「第X章」这类强模式，还是也接受纯数字行（「1」）？后者误判风险高。[ASSUMPTION] MVP 只做强模式，纯数字行不算。

## 9. Assumptions Index

- `[ASSUMPTION]` 章节标题独占一行。正文里「他说第一章写得不好」这类行内提及不算标题。
- `[ASSUMPTION]` 读者主要读中文小说，英文 `Chapter N` 作为兼容项，优先级低于中文模式。
- `[ASSUMPTION]` 一本 18 章的小说，段落数在数百量级，章节数组体积可忽略，无需分页。
