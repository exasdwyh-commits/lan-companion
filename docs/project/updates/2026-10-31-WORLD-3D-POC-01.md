# WORLD-3D-POC-01：澜的潮汐小屋

## 原型与启动

独立页面：`MALFOY-ENGINE/web/world-prototype/index.html`，使用项目已有 `web/lib/three.min.js` 和 B 母图，不引入其他项目的源码或素材。在工程根执行：

```sh
python3 -m http.server 8937 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8937/MALFOY-ENGINE/web/world-prototype/>。点击地面或四个地点按钮移动占位角色；鼠标拖动旋转，滚轮缩放；地点对应状态文字。仅本地服务，不读写个人数据。

## 已验与边界

- Ego Lite 实测 WebGL 页面载入 `ready=true`，图像加载成功；地面点击到达 `(1.45, 0.04)`，休息区按钮到达 `(1.65, -1)`，书桌按钮到达 `(-1.5, -0.9)`；已操作拖动和滚轮，场景未报错。截图 `benchmarks/2026-10-31-WORLD-3D-POC-01/room.png`。
- `bash scripts/project.sh check`：92/92，错误 0；7 条待办包括当前 Electron 源码与既有包不一致，本轮未构建。
- 当前角色是面向镜头的二维 Q 版贴图，移动是平移加轻微上下浮动，**没有骨骼走路、转身、坐下或手持书**；休息区只是走到附近。没有避障、寻路、自动生活、聊天、记忆、声音或正式真人 3D 模型。
- 测试页面独立，不在 App 内、未打包；画面为程序几何的空间草模，未达到参考项目的精细度。不同视角可能被墙遮挡。

## 参考项目研究

- [茉莉的小房间](https://github.com/norsizu/moli-room)：实际在 Ego 中打开并查看，房间布置有生活细节，角色坐在地毯上，支持拖动视角；项目文档记载昼夜天气、日常与物件互动。可借鉴“可观察的生活节奏”。代码与美术标注 CC BY-NC 4.0，若未来直接使用需履行其条件及复核第三方权利；本次未复制。
- [a small world](https://github.com/paulrobello/small-world)：README 描述微型世界、生物自主活动、昼夜和跟随视角，可借鉴环境和行为设计；仓库标注 MIT，具体素材及依赖另查。本轮只读项目介绍，未实玩。
- [Cozy Room](https://github.com/kiuckhuang/cozy-room)：项目介绍为第一人称房间，程序化室内细节，标注 MIT；可借鉴丰富的家具与灯光。本轮只读项目介绍，未实玩。
- [Roomlab](https://github.com/seofernando25/roomlab)：项目介绍提到等距房间、地格移动和坐下；可研究目的地与物件交互。本轮未核实复用许可，也未实玩。
