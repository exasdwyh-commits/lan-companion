## 完成内容

### 1. 电子书清洗（`read-ebook.py`）

原来的 HTMLParser 只拍平文本，链接文字、图注、页脚页码、目录行、脚注锚点都会进正文被念出来。
现在的规则（全部确定性、无网络）：

- 外链锚点与 `<sup>/<sub>/<figure>/<nav>/<head>` 内容整段丢弃，脚注「1」「2」不再留在句子里
- `img` 的 alt 从不进入正文；`figcaption` 一并丢弃
- 行级过滤：页码（`- 12 -`、`第 12 页`、纯数字行 2 个以上即视为分页）、目录行（`…… 12`）、
  图注（`图 3-1 …`/`Figure 1`）、纯符号行、无中日文/字母数字的行
- 重复出现 ≥4 次且不带句末标点的短行视为页眉页脚（书名/章节名）
- 剥完链接后剩下的「参见。」「更多内容见。」这类残句整行丢弃
- 空括号、标点前的悬空空格一并清掉
- 硬换行 TXT（32% 的行长度落在 30–50 字）还原成自然段；不足 15 字的短行当标题独立成段

### 2. 朗读稿（`lib/narration.js`，新增）

三层，纯规则零网络：

- **读音规范化** `toSpeech()`：`80后→八零后`、`90年代→九零年代`、`1998年→一九九八年`、
  `1990—2000→一九九零年到二零零零年`、`3.5%→百分之三点五`、`1/3→三分之一`、
  `2024-10-30→二零二四年十月三十日`、`10:30→十点三十分`、`5km/h→5公里每小时`、
  `No.1→第一`、7 位以上数字逐字读、破折号与重复标点收敛、超长括号注整段删。
- **语义分段** `splitParagraphs()`：句末对齐，单段目标 100 字、硬上限 160（TTS 服务端 300 字截断）。
- **旁白/对白切分** `splitScript()`：引号内单独成段。说话人按可信度依次取 ——
  ①「某某说/道/问」②引号后紧跟的旁白里出现谁（`“慢一点？”林夏转过身` 这种动作写法）
  ③「X 做了点事：」的句末冒号主语 ④旁白最近提到的角色
  ⑤都不是且不是段首，就沿用最近开口的人（`“……。”他把缸子放下，“……”` 后半句还是同一个人；
  整段只有一句裸对白也按小说惯例沿用）。`她/他` 靠代词票 + 名字用字判断性别，
  对不上就退回通用「女声/男声」——**叫错人比不做区分更糟**。
  段首的光秃对白不沿用，那是「换行=换人」的典型形态。

### 3. 多角色配音（`lib/voice-script.js` + `companion-media.js` + `main.js`）

### 4. 音色池实测（不是猜的）

Qwen3-TTS-1.7B-VD，同一句话的基频中位数：

| 音色 | 措辞要点 | F0 |
|---|---|---|
| 旁白（她本音） | 现有 world 配置 | ~218 Hz |
| f1 清亮少女 | early twenties, bright clear, lively | 251 Hz |
| f3 冷冽女声 | assertive, clipped, aloof | 198 Hz |
| f2 沉稳女声 | late forties, lower pitch, husky | 170 Hz |
| m3 少年音 | boy around fifteen, cracking | 143 Hz |
| m1 清朗男声 | young male, mid pitch | 106 Hz |
| m2 低沉男声 | deep, low, resonant | 79 Hz |
| old 苍老声音 | old man in his seventies, gravelly, hoarse | 95 Hz（本例实测 65–85） |
| child 童声 | six year old girl | 375 Hz |

两条关键结论：**同一段描述重复合成逐字节一致**（三次 md5 相同），所以角色不会中途换人；
**换句子音高只浮动 ±8%**。原稿里 `f2 warmly gentle adult female` 与旁白撞成同一个声音（193.5 vs 193.6 Hz），
已按实测重写。改描述前必须重新量，否则会把两个角色写成同一个声音。

### 5. 长样例暴露的三个问题（已修，同日）

第一版样例只有 5 段、23 秒，换成一整章（488 字）后立刻暴露出短样本看不出来的错误：

| 现象 | 根因 | 修法 |
|---|---|---|
| 「老陈」被分到 **清亮少女**（251Hz） | `OLD_HINT` 只认「爷/奶/翁/姥/婆/老头/老太」，不认「老 + 姓」这种称呼 | `OLD_HINT` 加 `^老(?!婆\|板\|虎\|鼠\|百姓\|外\|天\|娘)`，「老陈/老王/老张」落苍老声音 |
| 第 10 段老陈的台词被算成**林夏**说的 | 「沿用上一说话人」跨段乱串，覆盖了更硬的线索 | 新增引号后的旁白线索（`老陈看着窗外` → 老陈）；沿用降级为最后手段，且段首裸对白不沿用 |
| 老陈长句后半截掉进**旁白** | 延续判断只看「上一段是否以对白结尾」，段内第二个引号拿不到 | 改成段内跟踪 `lastSpeaker`，「他说完一句、旁白插一句、他又接着说」能接回去；纯旁白段落才清空 |
| 旁白末尾残留冒号（「周砚把伞收起来：」） | 冒号后面紧跟对白，念出来很怪 | 旁白段收尾时剥掉冒号 |

修完后 18 段角色归属全对，`node --test` 仍 58/58。

### 6. 两种阅读模式：实时阅读 / 精读配音（同日追加）

用户要求：小说交给 AI 先分析一遍，可选「精读多人配音」，也可选「实时阅读」不分角色。

| | 实时阅读 live | 精读配音 studio |
|---|---|---|
| 角色 | 不分，整段她自己的声音 | 分角色，各用一个音色 |
| 分析 | 不调模型 | 导入后后台分析，约 2 秒 |
| 等待 | 导入即读 | 导入即读（先用规则稿），分析完静默升级 |
| 适合 | 散文、教材、说明书、随手贴的文字 | 小说、剧本 |

实现要点：

- `lib/book-analysis.js`（新增）：把开头 6000 字交给模型，要回严格 JSON 的角色表
  （姓名 / 性别 / 年龄段 / 别名 / 是不是小说）。**只做角色表，逐句归属仍由规则层负责** ——
  模型看不全书，规则层看得到每一句，两边不要混。
- 角色表里的名字（含别名）作为「已知角色」喂回 `splitScript`，于是
  「老陈」「陈叔」会被认成同一个人、共用同一个音色；`她/他` 也能按性别落到最近匹配的角色身上。
- 分析失败（模型不可用 / 返回空 / JSON 坏）一律回退规则结果，状态记进 `analysis`，书照旧能读。
- `reading.json` 新增 `mode` / `analysis` / `rev`；`rev` 每次重切 +1，用于作废旧音轨，
  避免分析完成后还在播旧角色表合成的那一条。
- 面板：模式两个按钮 + 「重新分析角色」+ 一行分析状态（认出几个角色 / 正在读 / 失败原因）。

实测对比（同一段五句对话，外国音译名，规则层最容易翻车的地方）：

| | 规则推断 | AI 分析后 |
|---|---|---|
| 克里斯 | 清亮少女（错） | 清朗男声 |
| 「不给。」 | 没认出说话人 | 安妮 |
| 「我从来不后悔。」（后接「她把盒子…」） | 退回通用女声 | 安妮（按性别找到） |
| 冒号主语「克里斯笑了笑：」 | 切成「克里」，造出第二个角色 | 克里斯 |
