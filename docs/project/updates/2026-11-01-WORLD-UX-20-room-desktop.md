# WORLD-UX-20 · 小屋内容可视化与桌面动作

日期：2026-11-01；负责人：Codex / 01a191bf。用户授权丰富相册、书架、聊天、声音控制与桌面入口，并复用 dsh-pet。

## 已交付

- 小屋统一为暖纸、海玻璃绿的内容界面；960×540 与640×360适配。面板打开时调整导航和聊天栏，避免压住照片与书封。
- 相册分所有收藏、照片墙、冒险手账；照片支持大图、编辑标题/记录、贴墙/取下，原有导入删除接口保留。冒险手账读取已有 journey 数据；优先使用既有旅途配图，否则用四张馆藏配图，标明旅途故事/馆藏配图。没有制造新的实际出行记录或宣称生成了新照片。
- 小说书架使用封面、书名、章节/段落信息、搜索和当前阅读标记；当前页可展开，保留续读/暂停/上下段、导入电子书与粘贴文字。导入按钮放在书架前，避免书多时被埋到底部。
- 对话同步现有会话历史，流式片段与最终回答合成一条；输入法确认不误发；回复中防止重复提交。电视游戏键盘快捷键忽略输入框与内容面板。
- 声音页独立控制澜的人声开关/音量、停止当前播音，以及原有小屋环境音总开关/音量。设置持久化；停止当前语音会抑制当前回答后续分片。原有视频娱乐玩法保留。
- 右上角“来到桌面”复用已有 summon IPC。桌面默认使用 dsh-pet 原透明动画，并保留切回原版；24段素材、22个可选动作（另2段为拖拽与入睡过渡）。睡眠为入睡→循环→起床；双缓冲及加载代次保护避免旧加载覆盖新动作，复用原有拖动/漫游/返回世界入口。修复窗口重新激活后角色位置等下一帧才恢复、首下点击落空的问题；可见性恢复时立即还原位置并接收拖动。
