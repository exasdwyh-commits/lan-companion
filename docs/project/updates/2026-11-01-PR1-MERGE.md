## 三、合并时改了 PR 的三处代码

### 1. `runIntent` 的「改造小屋」分支其实从来没成功过

```js
// PR 原文
const job = llmChat(prompt, [], { noMemory: true, label: '（她改造小屋）' });
const r = await Promise.race([job, timeout]);
return r && r.ok ? r.text : '';
```

两个问题：

- **`llmChat` 不返回 `ok`**。它返回 `{text, voice, via, emo, ...}`。所以 `r.ok` 恒为 `undefined`
  → `generate` 恒返回 `''` → `decorate` 永远失败 → 改造分支是死代码。
- 就算返回了，`llmChat` 会走 `deliverReply` → `pushToCharacter`，**把她写出来的房间 JSON 当台词念出来**。

改成 `llmRaw`（本来就是「不带人格、不带记忆的一次性问答」，给书析用的那条）：

```js
generate: async (prompt) => {
  const r = await llmRaw([{ role: 'user', content: prompt }], { budgetMs: 45000, attemptMs: 18000, maxTokens: 900, temperature: 0.3 });
  return r && r.ok ? r.text : '';
},
```

### 2. 夜里每 20 分钟说一句「我在这儿安静待一会儿」

`decide()` 在夜里没有可行的事时返回 `rest`，而 `rest` 的 `cooldownMs` 是 **0**，
只受 `GLOBAL_COOLDOWN_MS`（20 分钟）约束 —— 也就是整夜每 20 分钟报备一次。
那是打扰，不是陪伴。改成静默：动作照记一笔（冷却照常推进），只是不出声。

### 3. 底栏还是 38/46 混排

`ui-skin.css` 只写了 `nav.bar button { width:38px }`（一个类 + 一个元素），
而 `index.html:108` 有 `.bar button.ic { width:46px }`（两个类 + 一个元素）—— 后者赢。
实测 `#bNight` / `#bSound` / `#bView` 三颗仍是 46×46，正是这次要收掉的毛病。
补一条 `nav.bar button.ic` 一起点名。
