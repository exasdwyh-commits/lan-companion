# UI-01 · 漂浮按钮与对话窗口玻璃外观

日期：2026-10-31；负责人：Codex / 当前聊天。用户要求窗口更精致，采用毛玻璃。

## 改动

| Before | After | Why |
|---|---|---|
| 深蓝实色面板与 emoji 按钮 | 珍珠白/冰蓝半透明面板、原创 SVG 鲸尾图标 | 统一伙伴的视觉识别，减少工具面板的厚重感 |
| 标题、标签、气泡各用不同深色块 | 轻量标题、分段导航、低饱和气泡、独立输入卡片 | 明确层次，留出阅读空间 |
| 只有 CSS 透明 | 展开时 macOS popover vibrancy 与原生阴影，收起时清除 | 由系统模糊窗口背后的桌面，避免图标带矩形材质底 |
| 样式内嵌业务 HTML | 独立 composer.css，保留所有业务 ID 和 WorkBuddy 的朗读模式/分析入口 | 后续外观维护有独立边界 |

窗口尺寸沿用：收起 64×64，内按钮 48px；展开 340×440。没有改变聊天、翻唱、电子书状态和事件。保留拖拽顶部/图标外圈、键盘焦点、中文输入、Escape 收起；减少动态效果与减少透明度偏好有对应样式。
