# 运行复查：桌宠尺寸、眼睛与表情接线

日期：2026-10-30。负责人：Codex / 当前聊天。

## 用户反馈与结论

用户要求测试，随后指出眼睛/表情不自然、人物偏胖、个头过大。实际截图确认独立绘制的眼睛偏圆、眼白过多；原默认按屏高 38% 放大，上限 360 CSS px，桌面占位过大。

逐帧核对 16 幅 atlas 的 `layout.width / rect.width` 与 `layout.height / rect.height`，比值全部为 1；当前 texture aspect 为 1，canvas 的 VIEW 留白也在投影中抵消。因此当前人物没有非等比拉宽。现有表演原画自身的发型、裙摆、鲸尾轮廓偏宽；本轮保留原画，没有靠压窄贴图改变身形。

## 已改动

- world：默认高度固定 180 CSS px，屏幕不足时等比缩小；不随大屏继续放大。托盘「桌宠大小」提供 140 / 180 / 220，主进程跨形态保留，重启恢复标准。预览放大系数保留。
- chibi-face：眼形改为较平缓的上眼睑、扩大虹膜覆盖、减少眼白和高光；开心实际绘制笑眼，单眼眨眼、困倦、闭眼、视线与语音口型保留独立参数。
- main/preload/world：增加只由主进程下发的 `character:size`；重建 desktop 窗口仍使用选择的档位，真人 640×360 不受影响。
- 复查原生回复时发现裸 `[calm]` 等标签没有解析。现在兼容八种已知裸标签和原 `[emo:…]` 协议，避免标签被显示/朗读；普通方括号正文保留。补齐 angry → pout、thinking → focused，业务身体/道具继续保持。
- 从真源重建 `dist/DeepWhale.app`，保留此前构建备份。重新启动的本轮测试 App 使用全新临时目录，没有复制个人设置或聊天历史。
