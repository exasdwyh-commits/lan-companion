### 翻唱：用户纠正后的方向

- 用户否定旧念词样例。两份原音频保留，标为历史念词基底实验、折叠显示，不再被「唱首歌」默认播放，也不作为翻唱质量验收。
- 核对 vendored Seed-VC 发现旧配置为 XLSR tiny、`f0_condition=False`。新产品流程固定使用 **44kHz F0-conditioned 歌声转换模型**，`auto_f0_adjust=False`，保留原曲音高和时长。
- 新流程：打开本地原曲 → Demucs 分离人声/伴奏 → Seed-VC SVC 换音色 → 混回伴奏。没有歌词 TTS 降级。

### 阅读

- 悬浮窗「读书 → 打开电子书」：原生文件选择器直接打开 **TXT / Markdown / EPUB**；也保留粘贴文字。
- TXT 支持 UTF-8/BOM、UTF-16、GB18030；EPUB 按 OPF spine 顺序提取文本，不执行 HTML、脚本或外链，不解压写文件。
- 拒绝加密、无文字、超大或无效文件；单书上限 200 万字，文本文件 8MB / EPUB 50MB / ZIP 解压内容 20MB。
- 朗读按短段生成；暂停/继续、停止、前后段。实际播放器 ended 才推进，不以模型生成完成冒充读完。
- `<数据目录>/reading.json` 保存当前书；`reading-progress.json` 只存书 ID 与段落位置，避免长书每读一段重写全文。旧 reading.json 可读回。
- 续读精度为当前段；切形态重取当前音色，重启不自动出声。当前是一本书，不是多书书架；扫描 PDF、DRM 和 OCR 未支持。
