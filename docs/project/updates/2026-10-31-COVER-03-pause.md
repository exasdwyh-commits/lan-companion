## 结论先说

用户在连续听过 6 个版本后判定「完全不行」，明确放弃这一路线。**没有达到可用听感，不标完成，改为暂停 + 待修补。**

根因不是某一次参数没调对。多次量测指向同一个上限：**Seed-VC 这条 SVC（歌声转换）链路，换音色只能换到「同性别、相近音区」的程度，源演唱者的咬字习惯、气口、音色骨架都还在，听起来始终是「王力宏在压着嗓子唱」而不是「她在唱」。**

配套修过的东西（都生效了，但救不回听感）：

- **音域八度误判**：`voice_range.py` 的 `f0_floor` 从 60Hz 提到 130Hz。之前把女声判成低八度（p05 报 76Hz），于是自动移调算出 +3 / +6，把人声硬拽上去。「虚、飘、放不开」有一半是这么来的。
- **能量门控**：以有声帧电平 p95−30dB 为界过滤混响尾音。修正后《爱错》p05 从 136Hz → 180Hz，推荐移调从 +3 变 +0。
- **削波**：混音 `amix normalize=0` 峰值顶到 0dBFS，AAC 硬夹出毛刺。加 `alimiter` 留 1dB 余量。
- **音色整形**：studio / warm / rich 三档（削 4–6kHz、抬 180–300Hz、补 10–13kHz、压缩、自带响度补偿）。

## 客观数据：换声确实发生了，但就那么点

用 campplus 说话人 embedding 的余弦相似度当尺子（`scripts/speaker-similarity.py`）：

| 版本 | cos(输出, 目标参考) | cos(输出, 磁性参考) |
|---|---|---|
| 孙燕姿版 | 0.770 | — |
| 清冷厚实版 | 0.738 | 0.595 |

两次都「比源更接近目标」，也都停在 0.74–0.77。参照系：同一说话人通常 >0.6 就算像，所以**不是完全没换过去**；但两个参考本身之间相似度就有 0.836 —— 这套 SVC 对「同为女声的不同音色」分辨力很弱，它更倾向于保住源曲的唱法细节。

清冷版人声实测 p05 195Hz / p50 315Hz / p90 415Hz，音区正常（没掉八度、没被顶破），所以问题不在音域，在**音色与唱腔的表现力上限**。

## 待修补清单（下次从这里开始，别从头试）

**P0 — 要真的像，必须换引擎，不是换参数**

1. **RVC（推荐先试）**：本机不能直接跑 —— 需要 Python 3.10 + fairseq，与现有 `.venvs/sing`（3.12）冲突，得单开一个 venv。前提是拿到 target speaker 的 `.pth` 模型 + `.index`；没有训练好的模型时 RVC 也不会比 Seed-VC 好多少，**这一步先去确认模型来源是否真有，再动手**。
2. **so-vits-svc 4.1**：同样是训练式方案，质量比 Seed-VC 更接近原唱音色，代价是要有该歌手的训练集。
3. **放弃「翻唱」改走「原创」**：MiniMax-Music-3 本地推理已验证可跑（ComfyUI，MPS）。词曲自己出，音色由模型人物设定决定，不再需要「像谁」。可控性差、但零版权风险，也最省事。

**P1 — 已知未修的具体缺陷（若继续用 Seed-VC，这些仍值得补）**

1. **2652Hz 处 +6dB 凸起**：用户点的「2–3kHz 刺」实测确认存在，现有整形只削了 3000Hz/−2dB，没覆盖 2652Hz。补 notch 即可，与换引擎无关。
2. **曲库旧条目待替换**：《爱错》旧版（+3 半音、削波，id `c9567501…`）仍在库内，参数已过时；若这条线不重启，可考虑直接移除，避免留一个「已知难听」的条目。
3. **歌姬模式作曲段仍走云端**：`vocalist-jobs.js` 作曲调用应切到本地 MiniMax-Music-3，与翻唱解耦，可单独推进。
