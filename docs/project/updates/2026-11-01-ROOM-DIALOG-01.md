# ROOM-DIALOG-01 · 小屋面板遮挡与「关了像停止」

> 2026-11-01 23:35 · WorkBuddy / 本聊天
> 用户：「如果是对话/读书，那个对话框遮挡，关了还直接停止了」

---

## 一、遮挡：面板正好压在她身上（已修）

先量，不猜。960×540 下实测：

| | 修前 | 修后 |
|---|---|---|
| 面板 | x=**432**, w=510 | x=**558**, w=384 |
| 她的投影位置 | x=457（半宽 17） | 同左 |
| 是否重叠 | **是**（432 < 474） | **否**（558 > 474） |

面板宽度 `510px` 来自 `lan-companion.css`，而澜站在屏幕中心 x≈457 —— 面板左边缘 432，
**整个人被盖住**。读书 tab 面板还更高（433px），下半屏一起吃掉。

### 一个容易踩的坑：那套 CSS 是死的

`lan-companion.js` 里有一大段 `CSS` 常量，用 `document.head.prepend(style)` 注入 ——
**prepend 意味着它排在 `lan-companion.css` 之前**，同属性一律被后者覆盖。
所以「改面板尺寸」改 JS 里那段是无效的（我第一次就改错了地方，实测宽度还是 510 才发现）。
**要改尺寸只能改 `lan-companion.css`。**

改法：`width: min(400px, 40vw)`。960 时落到 384 宽、左边缘 558，
她连身体一起露在外面；1280 时封顶 400，右侧留白更多。

## 二、「关了还直接停止了」：关面板其实没有停播

把 `CompanionPlayback.Player` 的 `stop/load/enqueue/command` 全部包了一层记录调用，
再走一遍「打开读书 → 播放 → 关闭面板」：

```
Player 调用序列: ["load:{…}", "stop:{fadeMs:0}"]
```

那个 `stop` 是 `load()` 自己内部的（`load(p){ this.stop({fadeMs:0}); … }`），
**关闭面板没有产生任何额外调用**；`host.media` / `host.stopVoice` 也一条都没发。

所以关面板**不会**停播。真实情况更可能是：面板盖住了她，也盖住了进度，
你以为停了 —— 关掉之后才发现已经读到别处去了。

### 但「状态只存在于面板里」本身是个缺陷

不管根因是哪一种，**把播放状态藏在面板里就是错的**。所以加了一个常驻状态胶囊：

- 朗读/唱歌在播时，左下角显示「正在朗读 4/120 [停止]」
- 和面板开关无关，面板关着也一直看得见
- 点「停止」= `stopVoice()` + `host.stopVoice()` + `media pause`，三件和面板里那颗按钮一致
- 状态变 `paused`/`ended` 自动收起；`stopVoice()` 也会顺手清掉

位置：`left:18px; bottom:126px`（聊天条正上方）。**第一版放在左上角 `top:52px`，
实拍发现压住了天气那几行**，所以挪下来了。

## 三、顺带修掉：面板一开，底栏整条消失

`lan-companion.css` 在 `≤780px` 里写了 `body.lc-panel-open nav.bar{display:none}` ——
面板打开时导航整条被藏掉，**只能靠面板的 × 才找得回来**。这属于「关了才回来」的那类毛病。

面板在小窗口里最高只到 `100vh - 68px`，底栏在它下面本来就不重叠，没必要藏。
改成 `display:flex`。实测 640×360 面板打开时底栏宽 243、`display:flex`。

## 五、已知边界

- **640×360 仍然会整幅盖住她**：那个宽度下放不下「400px 面板 + 居中的她」，没有更好的解。
  默认窗口是 960×540（WORLD-LAN-08 定的），在默认尺寸下不遮挡。
- **小窗口下面板打开时聊天条仍是隐藏的**（`≤780` 里 `.lc-root.panel-open .lc-chat{display:none}`，
  只有聊天 tab 例外）。这是 WORLD-UX-20 的既有设计，本次没动 —— 它影响的是「面板开着还能不能打字」，
  不是遮挡，也不是停播。
- **左上角天气块有几行文字发虚/叠在一起**：实拍里能看到，属于既有问题（不是本次引入），未处理。
- 状态胶囊目前只跟朗读/唱歌，**不跟聊天**。聊天有气泡和「澜正在想…」两处可见，没有再复制一份。
