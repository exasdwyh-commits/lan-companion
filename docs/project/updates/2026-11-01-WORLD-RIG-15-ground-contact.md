# WORLD-RIG-15 · 地面接触与躺姿腿型

- 日期：2026-11-01
- 范围：`MALFOY-ENGINE/web/moli-room/{lan-model.js,index.html}`
- 基础：Codex 的 WORLD-RIG-14 连续权重版本（v16，12 骨 + 4 权重蒙皮 + 2070 面接触切割）
- 证据：`benchmarks/2026-11-01-WORLD-RIG-15/`

## 用户反馈

> 现在好很多了，你再优化，要合理，躺下，坐着起身脚下穿到地板，这些穿模要注意

拆成两个独立问题：① 坐姿和起身时脚穿地板；② 躺下的姿态不合理。

## 问题一：坐/起身脚下穿地

### 定位

`pose()` 里根骨高度沿用了上游公式：

```js
rootYm = (C.y - .19) * .78 * (1 - lying) + .14 * lying
```

上游 `C.y` 是髋部高度：站立 0.19、坐下 0。所以坐姿 `rootYm = -0.148` 米，即**整个人下沉 14.8 cm**。

问题是墨水体（0.78 身高的细身）腿够长，而 Q 版这个模型**整条腿只有 0.1115 米**（髋 0.175 → 踝 0.032，两者都是身高比例）。髋部降得比整条腿还低，脚只能插进地板。

实测（`D.lanModel.dbg`）：

| 时刻 | `rootYm` | 鞋底相对地面 |
|---|---|---|
| 坐定 | −0.1482 | −0.029（穿地 2.9 cm） |
| 起身 1.2 s | −0.1481 | −0.029 |
| 起身 1.7 s | −0.0404 | ≈ 0 |
| 走路 | ≈ 0 | 0 |

起身时根骨要 0.5 秒才爬回地面，这段时间脚一直陷着——正是用户看到的现象。

### 顺带的第二个偏差

脚的 IK 目标用上游偏移：

```js
( foot.y + .166 ) * .70 * G
```

`+0.166` 是墨水体站立时 `fl.y` 的绝对值（STAND 是 −0.166），`0.70` 是它的缩放系数。这个组合在 Q 版上，坐姿会把脚**抬高 3 cm 悬空**——髋降了、脚却没跟着落。

### 修法

三层，从软到硬：

1. **臀部落地限制**：坐姿时根骨不低于 `HIP_SEATED(0.072) − 髋骨静止高(0.175) = −0.103`，骨盆不会再沉到地板下。
2. **脚目标接地钳制 + 坐姿强制踩地**：`sole` 不得低于地面；坐着时用 `seated` 权重把脚目标混合到地面（站立保留上游偏移，行走踏步不受影响）。
3. **腿长兜底**：解完 IK 后若最低脚踝仍在地面之下，说明腿真的够不到，此时抬整个身体。正常情况下第 2 层已经保证，第 3 层不触发。

## 问题二：躺下的腿翘起来

### 定位

躺姿不参与接地判定，所以纯看骨骼。实测骨骼世界坐标：

```
髋  y=0.888   z=-1.060
膝  y=0.924   z=-0.948     ← 比髋高 3.6 cm
头  y=0.904
```

膝盖比头还高，腿朝上斜。两个原因叠加，都是几何必然：

1. **bind 姿势本身脚比髋靠前 3 cm**。`J.ankle.z − J.hip.z = 0.030`。身体绕 X 转 −90° 之后，局部的「前」变成世界的「上」，所以腿天然上翘 **11.8°**。
2. **目标距离比腿长略短**，IK 必须弯膝；而 `hint` 在躺姿是 `(0,0,1)`，转换后同样指向**正上方**，膝盖就朝上鼓出去。

`dbg.legDzL` 一旦不为 0，`legTiltDeg = atan2(legDzL, −legDyL)` 就直接给出倾角，不必靠目测。

### 修法

躺下时把腿目标改成「去掉前倾 + 按腿全长伸展」：

```js
const dx = J.ankle[s].x - J.hip[s].x, dy = J.ankle[s].y - J.hip[s].y;
const d = Math.hypot(dx, dy);
const legLen = (|髋膝| + |膝踝|) * 0.998;   // 全长，几乎不留弯
target.x = hip.x + dx / d * legLen;
target.y = hip.y + dy / d * legLen;
target.z = hip.z;                            // 前倾归零
```

伸展量取到 0.998 后 `along ≈ l1`，`h = √(l1² − along²) → 0`，膝弯项自然消失，不需要再去猜 `hint` 该指哪。

## 调试设施（保留）

- `?bones=1`：在 12 根骨上挂彩色小球（`depthTest:false`），用于判断「骨骼到位了但网格没跟」还是「骨骼本身歪了」。这次靠它排除了权重问题。
- `lanModel.dbg`：每帧导出 `{rootYm, soleL, soleR, legDyL, legDzL, lying}`。`sole` 是**相对 `moli.position.y` 的自身地板平面**，躺姿下无物理意义。

## 剩余限制

1. **振袖张开**：站立双手举高时大振袖展开成翼状。Q 版大袖 + 单网格的固有限制，根治要在 Blender 里重做袖口拓扑。
2. **被子尺寸**：躺下时被子按原墨水体（0.78 细身）铺设，盖不住更宽的 Q 版身体。属场景侧资产问题，不在 `lan-model.js` 范围。
3. **`dist/DeepWhale.app` 仍是 00:44 旧资源**，Electron 的 `WORLD_PAGE` 指向 `web/live2d/world.html`，不加载小屋。本轮修复只在源站可见，进 App 要等 WORLD-LAN-07。
