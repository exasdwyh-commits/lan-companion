# WORLD-SCENE-03：潮汐小屋场景细节

## 参考与实现

参考 [茉莉的小房间](https://github.com/norsizu/moli-room) 的日常与地点互动，以及 [Cozy Room](https://github.com/kiuckhuang/cozy-room) 的程序化室内场景思路；两者仅作设计参考，本轮未复制项目代码或素材。

独立 Three.js 小屋增加窗帘、窗外云与岛、墙上书架、桌灯和杯子、被褥与床头灯、简易接触阴影与日光；夜色同时改变窗外颜色。可直接点击窗户、书桌和床前往地点；限制视角旋转范围，减少从墙背观察时遮挡。保留原网格寻路及控制按钮。

## 验证

- `node --check MALFOY-ENGINE/web/world-prototype/world.js` 通过；`bash scripts/project.sh check` 为 92/92、错误 0、6 条待办。
- Ego Lite 中 `ready=true`；实际点击床后到达休息区，点击书桌和窗户可切换目标，抵达窗边后切换夜色成功。夜景截图：`benchmarks/2026-10-31-WORLD-SCENE-03/night.png`。
- 本轮只验证固定窗口下的基本交互；未覆盖所有视角、长时间性能和移动设备。

## 后续与边界

角色仍是二维贴图，场景是程序几何草模；没有真正的骨骼走路、物件操作、持书、坐卧或记忆。寻路仍是矩形障碍和正交网格，未覆盖新增床头小柜的完整碰撞；不是正式游戏场景或应用集成。Hyper3D 可导出角色和骨骼变形仍待解决。仅在独立页面交付，未打包 App。
