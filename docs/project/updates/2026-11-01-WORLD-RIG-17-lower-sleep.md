## 用户诉求与判读

「上床上就可以接受穿模了」＝过渡（上床/起身）过程中的穿模不再作为验收项，优先保证躺定后的形态。
「人可以往下点」＝躺定后仍然显得浮在床面上方，继续下沉。

## 一、床垫顶面实测 0.53（不是 0.46）

上一轮记的 0.46 是床架边缘。这一轮对整个床面做射线网格扫描（x −2.1~−0.6 步长 0.15，z −2.0~0.2 步长 0.2）：

```
x=-1.35  0.588 0.604 0.53 0.53 0.524 0.52 1.033 ...
x=-1.20  0.570 0.598 0.53 0.53 0.502 1.174 ...
x=-1.05  0.530 0.530 0.53 1.048 0.492 ...
```

大片区域稳定在 **0.52~0.53**，1.0 以上那些是被子抬起处，0.46 只出现在靠墙的床架边。

她的躯干（`spine` 骨控制顶点）底面在 0.66，**离床面 0.13 m**，所以被子只能在身体周围抬起、不能盖到身体上方——这就是「人在被子上」而不是「人在被子里」。

## 二、修法

### 1. 躺姿下沉 0.13 m

```js
let rootYm=(C.y-.19)*.78*(1-lying)-.07*lying;   // 原 +.06
```

站立/坐姿不受影响（`lying` 项为 0）。

### 2. 被子覆盖盒：8 段细分 + 胸口最厚曲线

原来的 `BoxGeometry(1,1,1)` 只有 8 个角点，楔形 taper 只能从头顶到脚底线性变化。实测它的**峰值厚度只有 0.31 m**（`scale.z=.56` × 脚端 taper .55），而她躺下后躯干厚 0.33 m——被子永远差一点点盖不住。

改为 `BoxGeometry(1,1,1,1,8,1)` 沿身体长轴细分，厚度按插值曲线给：

| 位置（−0.5 脚端 → +0.5 头顶） | 厚度系数 |
|---|---|
| −0.50（脚端） | 0.70 |
| −0.25 | 0.95 |
| 0（胸口） | 1.00 |
| +0.25 | 0.86 |
| +0.50（头顶） | 0.06 |

头顶那端几乎压平，被子边缘自然落在脖子上，头露在外面。

同时：
- `scale` 由 `0.92 × len × 0.56` 改为 `1.14 × len × 0.48`——加宽是因为裙摆铺设后向两侧张开超过肩宽。
- 盒子中心沿世界 Y 抬 `0.05`：骨骼走的是身体中轴，布料要护住她的**背**，不居中就会整体偏低。
- `len` 由 `dist + 0.42` 收到 `dist − 0.12`，头端停在肩膀。

### 3. 裙骨躺姿零旋转

实测同一帧下裙摆（`skirt` 骨控制顶点）最高点随转角变化：

| 裙骨 X 转角 | 裙摆 max y | 裙摆 min y |
|---|---|---|
| **0** | **0.866** | 0.190 |
| −0.28 | 0.893 | 0.205 |
| −0.50 | 0.897 | 0.227 |
| −0.70 | 0.886 | 0.253 |
| −0.90 | 0.862 | 0.283 |
| −1.10 | 0.826 | 0.318 |
| −1.40 | 0.791 | 0.371 |

上一轮用的 −1.15 把她裙摆转到世界 `(0,−0.91,+0.40)`——**垂直戳进床垫**，布料被压住只剩腰部一圈，大腿反而露出来；这一轮先改到 −0.28 又发现它在胯部顶到 0.893，比被子还高 0.03，从被面戳出来一个白尖。

**答案是零旋转**：站立时裙摆沿局部 −Y 下垂，身体绕 X 转 −90° 后这个方向正好映射到世界 +Z，也就是它本来就会沿床面朝脚摊开——不需要任何额外旋转。转角为 0 时裙摆最高点最低（0.866）、展开面积最大、盖腿最全。

```js
b.skirt.rotation.set(-seated*.25*(1-lying),0,...);   // 躺姿项归零
```

## 四、仍然存在的边界

1. **Q 版头径 ≈ 躯干厚度**。她躺下后头高（0.864）和躯干厚（0.33）几乎相等，所以被子一旦盖住躯干就一定与头顶齐平。现在靠「被子在 z −1.18 处收低 + 头在边界之外」让头露出，不是靠被子更低。
2. **长发软物仍可能轻微穿出被面**（俯视可见一两个小白点）。头发由 head 骨整块驱动，没有物理，无法逐根处理。
3. **裙摆背面会插入床垫**（min y 0.19，床面 0.53）。俯视与床尾视角都被被子挡住，看不到；侧视若贴近床沿可见。零旋转的代价。
4. **过渡帧（上床/起身）仍会有穿模**——用户已明确接受，本轮不再处理。
5. `dist/DeepWhale.app` 内 `web/moli-room/` 仍是 00:44 的旧资源，Electron `WORLD_PAGE` 指向 `web/live2d/world.html`，不加载小屋；本轮只能在源站可见。
