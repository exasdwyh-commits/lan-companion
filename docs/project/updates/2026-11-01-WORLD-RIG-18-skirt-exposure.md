# WORLD-RIG-18 裙装走光：单面裙片 + 裙内衬 + 安全裤

- 日期：2026-11-01
- 负责人：WorkBuddy（本聊天）
- 用户原话：「穿裙子在床上就走光了 这个要优化」
- 结论：已修好，**根因不是姿态，是裙片只有单面**。补一层反面内衬 + 一件裙内安全裤，
  从任何角度往裙里看只剩布料。真机已重启为新构建（`dist/DeepWhale.app`）。

---

## 一、根因

**裙片是单面网格（single-sided sheet）。** 面朝外的正面正常渲染，反面被 `FrontSide` 剔除，
于是**从裙摆下方看进去时，视线穿过裙壁直接落到她的皮肤上**——看起来就是"裙底全露"。

这条不是摆姿能解决的：

- 躺下（`pitch = -π/2`）后裙的锥口正对床尾，从床尾一眼就看进去；
- 坐下（`read_bed`）时锥口朝前下方，低机位同样看进去；
- 她穿的是**短裙 + 光腿**，裙内没有任何"内裤"几何可以挡住视线。

RIG-16/17 两轮调的是"被子盖不盖得住""裙摆有没有戳穿被面"，都以**外部轮廓**为准，
所以一直判"床尾看不出裙底"；而用户是**绕视角看进去**的，落在这些断言的盲区。

## 二、怎么修的

两件东西，都挂在 **`lan-skirt` 骨**上，**不改 GLB、不改权重、不动外形轮廓**：

### 1. 裙内衬（`lan-skirt-lining`）

把**同一份**几何里"三个顶点都由裙骨主导"的三角面抠出来（36,277 面）另画一遍，
材质 `MeshStandardMaterial({ color: 0x1b2747, side: BackSide, skinning: true })`。

- 共享 position/normal/uv/skinIndex/skinWeight，所以**变形与裙片完全一致**，不可能走形；
- 只画反面 ⇒ 从外面看永远在裙片之后，**外轮廓一个像素都不会变**（站立对照见 `57`/`58`）；
- 只取裙骨分组 ⇒ 身体其他部位的反面不会被意外画出（有些面的绕序本来就反，全量反画会出暗块）。

### 2. 安全裤（`lan-bloomers`）

裙锥的口子本身是开的，只有内衬还挡不住正对锥轴的视线，所以在裙内补一件深藏青实体：
椭球 0.128 × 0.100 × 0.112 m，中心在裙骨原点下方 0.072 m（绝对高度 ≈ 0.163 m，正好在髋 0.175 之下）。

- 半径远小于该高度处裙片的半径（≥ 0.22 m），**物理上不可能戳出裙外**；
- 只从裙摆开口看得见，正常机位完全不可见。

**为什么不直接把材质改 `DoubleSide`**：整件是一个网格、一个材质，改 `DoubleSide` 会让
头发、袖子、身体所有薄片的内面一起出现，且和外壳共面处容易起冲突；而 36k 面的内衬只覆盖裙。

整段包在 `try/catch` 里：这只是观感修补，**不能因为它的异常把模型整个 fallback 成墨水体**
（`boot()` 抛错会走 `fail()`，澜会变成一团黑影）。失败时 `info.costume.error` 记下原因，
裙片退回原样，模型照常可用。

> 中途有一版把 `const skirtFaces = buildSkirtLining(...)` 误删成 `let ... = null`，
> 浏览器里仍然 `state: ready`、只是 `info.costume.liningFaces` 会变成 0——**所以验收必须看
> `info.costume` 与截图，不能只看 `state`**（RIG-13 就是只验状态值被坑过一次）。

**为什么不用"躺下时压扁裙骨"**：RIG-17 已实测裙骨转角的敏感度（0→0.866、−0.28→0.893、
−1.1→0.826），任何额外扭转都会把裙撑立起来戳穿被面；压扁会同时影响混权到髋骨的顶点，
形变风险高且救不了"锥口对着镜头"这件事。

## 三、验证

### 染色法（决定性证据）

把身体按主导骨拆出三组面各染一色：**腿→纯红 15,181 面、手臂→纯绿 15,009 面、裙→纯蓝 36,277 面**。
躺姿、床尾正对锥口拍摄（`90-tag-bones.jpg`）：画面里**没有任何红色**——裙口里看不到腿；
绿色只在她两侧露出的手上（正常）；裙面与花边全部是蓝色。

再补两组对照：内衬/安全裤染品红（`71`）后裙内整片变品红；把**身体**染青（`72`）后，
裙内残留的"粉色带"跟着变青 —— 说明它是**同一网格上的花边**（裙骨主导），不是皮肤。

## 五、剩余限制

- 内衬把 36k 面多画一遍，多一次骨骼蒙皮 pass；真机帧率未见异常，但**未做逐帧耗时对比**。
- 安全裤是刚体，挂裙骨不挂腿骨。腿大幅弯曲时它不会跟着腿变形（它只负责挡视线，
  所以不需要跟），但极端姿势下可能出现"安全裤与腿的相对位置偏一点"。
- 花边、头发这类薄片如果从特定角度反向看，仍可能看到内衬的深色（比原来透到皮肤好，但不是零）。
- 上床/起身过渡帧的穿模（RIG-17 用户已接受）本次未处理。
- 真机画面仍未截图确认（本机屏幕会话锁屏，`screencapture` 与 `capturePage` 都拿不到画面）；
  以上判定全部来自 `ego-browser` 离屏渲染。
