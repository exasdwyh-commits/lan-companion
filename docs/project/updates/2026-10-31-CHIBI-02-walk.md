## 交付内容

1. **6 帧走路图集**（`assets/whale-chibi-walk-v1/`）：agnes-image-2.5-flash 图生图（参考 v2 立绘），白底 flood-fill 转透明，无重采样；`source.json` 记录 rect/校验数据/处理/许可注记。首次派单撞图像服务 503（queue full），后台重试循环第 1 次重试成功。
2. **嵌入管线**（`scripts/prepare-chibi-texture.py`）：可选识别走路图集目录，校验 4-8 帧、边界、无重叠后生成 `chibi-walk.js`；图集缺失时构建与 `--check` 干净降级（含过期文件清理）。
3. **Director 走路场景**（`chibi-performance.js`）：`SCENES.walk` 空帧占位；`locomotion==="walk"` 且 idle、无事件/表演/手势时进入 walk，0.16s/帧轮播 `state.walk`；反应/拖拽/业务活动优先级全部高于走路；`frame` 保持 0 作安全回退。
4. **渲染器走路通路**（`chibi-renderer.js`）：`loadWalk`（校验+贴图+四边形缓冲）、`renderWalk`（归一化帧高+底部锚定+tilt/bob，独立四边形绘制不走 16 帧网格）；`render()` 在 walk 场景分流；绘制后刷新 idle UV 保住命中测试轮廓。
5. **world 接线**（`world.html`）：加载 `ChibiWalk`（缺失静默降级，错误记入 `__walkError`）；`performer.tick` 传入 `walkEnabled/walkFrames`。
6. **预览**（`motion-preview.html`）：情境轮播新增"走两步"段（roam 驱动真实 walk 状态）。

## 发现并修复的 bug

`renderWalk` 不经 `upload()`，从未设置 `uOpacity` uniform，着色器 `alpha *= uOpacity` 默认 0 → 走路首帧全透明。修复：路径内显式 `gl.uniform1f(this.opacity,1)`。

## 限制与待验

- **App 内真实观感未验**：harness 浏览器加载重型 world 页多次崩溃，未在正式 app 窗口/预览页人眼确认走路效果；用户开 `motion-preview.html` 或召唤桌宠漫游即可验收（预期：走动时 6 帧循环、停下回 idle、拖拽惊讶、点击台词不受影响）。
- 走路帧为整帧美术，走路期间独立面部层暂停（眨眼/追视在走路时不叠加）；如需走路眨眼，后续给走路帧补 face 锚点。
- 图生图身份一致性由参考图+蓝色占比佐证，人工视觉复核未做（当日视觉模型不可用）。
- 生成尺寸被服务端降为 1024×1024（请求 1254）；对 180-220px 显示足够。
