## 用户反馈

> 还是有点穿模，睡觉的人物太高了，人没在被子里。而且躺着这个还裙底也不美观。

三条指向同一个对象：躺姿（`life.at === 'lie'`，`act === 'sleep'`）。

## 根因：整套躺姿常数是按 0.78 m 的墨水体标定的，这套 Q 版几何全对不上

实测数据（床垫顶面 **y = 0.46**，枕头 y 0.445–0.615 / z −1.86…−1.48，毯子原始 z −1.35…0.10）：

| 项 | 实测 | 后果 |
|---|---|---|
| 身高（头顶到鞋底） | **1.30 m** | `PL.lie` 锚点 z = −0.78 让她头顶冲到 **z = −2.03**，床头板在 −2.02 —— 头直接穿出床外 |
| 躺姿 `rootYm` | 原 0.105 | 髋落在 **y = 0.808**，离床垫 0.35 m，整个人悬空 |
| 毯子覆盖盒 | 0.40 × 1.07 × 0.30 | 身体宽 0.95、厚 0.72 —— 盒子只抬起被子中间一条，两侧塌在床边 |
| 裙骨躺姿旋转 | +1.26 rad | 绕 body X 转 +72° 后轴向世界 (0, +0.95, −0.31)，即**朝天花板**，等于把自己架在裙撑上 |
| 髋距 / 腿长 | 0.176 m / 0.146 m | 沿身体轴伸直 → 双腿张开 **31°**，脚底比床面高 **0.25 m** |
| 手臂 | 沿用站立偏移 | 两臂张开，手腕穿出被子两侧 |

原先 `rootYm` 用 0.105 时，"最低点 0.494 ≈ 床面"看着像贴住了，其实那 0.494 是散开的头发，躯干仍在 0.75 以上 —— 这是上一轮判断失误的直接来源。

## 修法

```js
// 1. 沿床面滑到头这一端（只在她躺着时生效，权重 lying 平滑过渡）
const LYING_SLIDE = .42;
b.root.position.set(0, rootYm*G, LYING_SLIDE*lying*G);

// 2. 落到床垫上，而非停在 moli 的"地板平面"
let rootYm = (C.y-.19)*.78*(1-lying) + .06*lying;

// 3. 裙骨朝下折叠（+1.26 会让它朝上），既压平轮廓又合拢裙摆
b.skirt.rotation.set(-seated*.25*(1-lying) - 1.15*lying, 0, ...);

// 4. 双腿收向中线并压到床面
target.x = lerp(target.x, H.x*.30, lying);
target.y = lerp(target.y, H.y - .105*G*.998, lying);
target.z = lerp(target.z, H.z - .100*G*.998, lying);
hint = (sign*.18, fh.y, 1)          // 膝朝床面，不再朝两侧

// 5. 双臂折到身侧（用模型自己的肩→腕向量，不写死绝对坐标）
const rest = J.wrist[s].clone().sub(J.shoulder[s]);
target = lerp(target, sr + (sign*.042, rest.y*.90, rest.z*.90), lying);

// 6. 毯子覆盖盒改成楔形：头端收薄、脚端收窄，被子才会"盖着人"而不是"扣着一个筐"
//    头端 z*0.16 / x*0.74，脚端 z*0.55，中段满尺寸 0.92 × 0.56
```

`syncBlanketProxy` 里第一次调用时把自己的 `BoxGeometry` 换成变形后的楔形，并用 `userData.lanQuiltShape` 防止重复替换。

## 仍然存在的限制

1. **头没正好枕在枕头上**：往里挪 0.13 m 反而让被子重新盖住脸（覆盖盒跟着骨骼走，相对关系不变），已回退。要真对上枕头，得改场景里枕头与毯子的相对布局，属场景资产范围。
2. **被子鼓包 ~0.40 m**：她躺下时躯干（含大振袖与荷叶边裙）实测厚 0.50 m，比 0.78 墨水体厚一倍。被子形状已按楔形贴合，但无法压到真人的 0.3 m。
3. **躺下时长发会有一小撮穿出被子边缘**（软物，被模糊抬升覆盖不到），视觉上接近"头发露在被子外"。
4. 未接 Electron；`dist/DeepWhale.app` 内仍是 00:44 旧资源，此修复只有在源站可见。
