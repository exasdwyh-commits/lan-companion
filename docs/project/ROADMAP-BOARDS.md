# 三板块功能路线图（ROADMAP-BOARDS）

> 状态：2026-11-01 规划稿，依据用户三板块定版 + GPT/Gemini 评审并入版方案。行为契约与工程切片见 [LAN-COMPANION-REBUILD-PLAN](LAN-COMPANION-REBUILD-PLAN.md)；任务领取以 [TASKS](TASKS.md) 为准。本图回答"先做什么功能、做到什么程度算好"，不重复切片定义。

## 主线路径（一句话）

**模型观感确认 → 小屋接进 App（WORLD-LAN-07）→ 语音真机验收 → 契约冻结（LAN-CONTRACT-01）→ 跨重启接续试玩（PILOT-REUNION-01）→ 她的自主生活 → 故事包 → 桌面增强 → 发布准备。**

---

## H1 近端：把"家"搬进产品（当前主线）

| # | 功能 | 内容 | 验收 | 依赖/负责人区 |
|---|---|---|---|---|
| H1-1 | 澜模型定版 | 用户实看混元 GLB + RIG-13 修复（被子/鞋/裙）后点头；不点头回炉 | 用户一句话确认，记录进 TASKS | TASKS 的 16:10 协调声明已记录用户认可 RIG-17 形象 |
| H1-2 | 小屋接 Electron（WORLD-LAN-07） | moli-room 成为 App 主窗口内容：托盘入口"她的小屋"、窗口策略复用 world 规格、与悬浮聊天/音频仲裁共存；房间物件可点击（床/电视/书桌） | 真 App 内打开小屋、看电视玩游戏、聊天不双播、切形态不断线 | LAN-07/08 已接并打包；180/180 当前源包一致；真机音频与形态切换体验待验 |
| H1-3 | 语音真机验收（一批） | WAKE-01 唤醒 + VOICE-02/03/05 + AIRI-REF-01 同一次试用收口：叫名字→说话→她答→打断 | 真麦克风 10 轮，无叠播/无自言自语接话 | 用户在场 15 分钟 |
| H1-4 | 契约冻结（LAN-CONTRACT-01/P1-0） | Event/Snapshot/Proposal/ContentPack/世代号/音频租约 JSON Schema + Mock 单测 | 各 agent 可并行开发，不再往 main.js 塞私有 IPC | 独立新文件，可立即领取 |
| H1-5 | 小屋内朗读可视化 | 读书时她在书桌前坐下入戏，字幕条/书页进度在房间内呈现；暂停即起身 | 真书导入→听一段→暂停→她起身，重启续读位置一致 | LAN-08 面板与原播放链接线已打包；假宿主交互通过，真书听感/重启续读待验 |

## H2 中期：接续感与自主生活（差异化核心）

| # | 功能 | 内容 | 验收 | 备注 |
|---|---|---|---|---|
| H2-1 | 跨重启接续试玩（PILOT-REUNION-01） | 共读→她提议（引用书位）→共写进草稿→定稿留纪念物→重启/切形态后从原处继续 | 任一环断链即整轮不通过 | 整合 H1 各项 |
| H2-2 | 纪念物系统（P1-4） | 确认后的作品/事件生成小物件摆上小屋书架/床头；可撤销（软失效） | 重启仍在；撤销即消失且历史可查 | 与内容包 ID 关联 |
| H2-3 | 自主独处（P1-2） | App 开着但用户忙：她自己读书/浇花/打游戏/午睡，活动有开始-完成-被打断轨迹；次日能解释"为什么" | 用户回来看得见她在做事，引用事件说明动机 | 拒绝邀请→冷却，不轰炸 |
| H2-4 | 轻确认气泡（小屋+桌面） | 她的邀请以非模态气泡出现：桌面 3 分钟无响应自动转"独处备忘"；免打扰/全屏自动静默 | 不抢焦点、不弹窗、不连续审批 | Gemini §4.2 规格 |
| H2-5 | 上下文编译器（P1-1 内） | 所有 LLM 入口统一喂"真实且未失效"事件；捏造引用被拦截降级 | journey 类假旅行问题绝迹；`referencedEventIds` 校验生效 | 根治编造记忆 |
| H2-6 | 桌面 Q 版增强 | 16 姿态锚点标定接线；碎碎念引用真实记忆；工作状态六档接入日常 | 桌面形态有明确"她在陪你工作"表达 | 二阶段模块，不抢小屋资源 |
