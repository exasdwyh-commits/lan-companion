# 困倦趴屏待机首帧

`whale-sleepy-transparent-v1.png`：内置 imagegen 生成，参考当前撒娇视频第190帧的角色脸、鲸鳍饰品与服装。1536×1024 RGBA，已检查存在真实透明像素。原始输出保留于 Codex generated_images。

`image-prompt.txt` 为实际生图提示词；`video-prompt.txt` 为图生视频提示词。

用途：用户自行生成安静待机视频。当前未替换桌宠运行素材。主体脸靠交叠双臂，支撑面不在图片中，以便贴合屏幕或不同背景的边缘。

视频优先保持姿态稳定，只做一次慢眨眼和极轻呼吸。若生成平台不支持透明背景视频，改用均匀绿幕输出，再导入桌宠。
