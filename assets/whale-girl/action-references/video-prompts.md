# 鲸鱼娘后续视频动作

统一约束：同一成年角色，固定机位、焦距与构图，脸型、蓝发、鳍耳、服装和饰品保持一致。动作小而自然，肩膀保持放松。无镜头运动、无突然变焦、无新增人物。绿幕均匀纯色，不出现绿光反射。

1. 安静理发，8–10 秒：从双手自然放下、正视镜头开始；自然眨眼，缓慢将一缕头发别到耳后，手放回原位，回到起始姿态。首尾脸部位置、视线与双手位置匹配，末尾保留 1 秒稳定状态。
2. 困倦托腮，8–10 秒：保持脸颊轻靠掌心、肘部有支撑，只表现自然呼吸、一次缓慢眨眼和轻微视线变化，最后回到完全相同的托腮姿势。不要反复晃肩，不要张嘴讲话。
3. 准备躺下，6–8 秒：从床边侧坐开始，一只手稳稳撑住床面，慢慢侧身靠向枕头，头部最终落在交叠双手上并闭眼。使用现有睡眠视频干净首帧作尾帧，匹配床、镜头、头部位置和光线。这是单向过渡，不要求首尾相同。
4. 温柔醒来，6–8 秒：使用现有睡眠片段干净首帧作为视频首帧；先微微睁眼，再用肘部支撑缓缓抬头，另一只手轻轻整理脸旁头发，最后安静看向镜头。不要突然坐起或大幅伸展。这是单向过渡，不要求首尾相同。

参考板用于选动作。正式生成时每次只上传对应的一格，并同时提供角色原始设定图；避免把整张四格图直接做成视频。床边动作参考构图与现有睡眠视频可能仍有差异，需在视频工具内用现有真实帧锁定首尾。
