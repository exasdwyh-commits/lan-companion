## 正式原画制作顺序

1. 以 B 母图的同一画布和坐标为基准，制作可编辑分层 PSD；先补脸底、发后、肩膀和四肢关节的遮挡部分，不直接拼贴上述参考稿。
2. 五官拆成左右眉、眼白、虹膜、眼睑、高光和嘴部；头发拆前发、两侧发、后发及需要摆动的发束；两只鳍耳单独拆分。
3. 身体、衣领、领结、裙摆、左右上臂、前臂/手、左右腿/鞋、鲸尾与尾鳍分层；肩肘髋膝和裙后按运动范围补画。左右动作独立，前后遮挡关系要能调整。
4. 在原尺寸复合图和桌面约 180px 预览检查轮廓、眼睛、嘴及关节；再在 Cubism Editor 制作网格、变形器、参数和物理，导出运行模型。
5. 先做眨眼、追视、口型和小幅摆尾；舞蹈需单独设计手脚、重心和节拍，验证大幅动作是否需要额外替换部件。哼唱需独立音频及口型同步。

尚缺：可编辑 PSD、对齐补画、Cubism 工程、澜的运行模型、舞蹈动作及哼唱。参考图不进入应用资源或发布包；来源和权利在发布前复核。
