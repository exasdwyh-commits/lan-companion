# 鲸鱼娘安静陪伴与睡眠测试素材

新视频 (3) 作为已经睡着的完整场景。它没有躺下动作，当前进入睡眠时直接切场景。

- 原片：`source.mp4`，保留未修改文件。
- 修补：`sleep-repaired.mp4`，用原片干净帧覆盖两处水印区域，局部布料/背景运动可能减弱。
- 播放：`../whale-video-test/bed-sleep-loop.mp4`，静音，约 9.54 秒；末尾与开头 0.5 秒混合后循环。
- 趴屏播放：`../whale-video-test/quiet-idle-loop.mov`，约 7.54 秒，ProRes 4444 透明通道；灰绿原背景使细发边缘仍有少量色边。
- 生成脚本：`../../scripts/prepare-whale-rest.py`，依赖 Python、OpenCV、NumPy、ffmpeg。

## 交互

约 60 秒无操作进入趴屏陪伴，约 300 秒进入床上睡眠。定时检查有间隔，因此实际切换略晚。右键可选“趴着陪我”“让她休息”，点击睡眠场景或打开聊天唤醒。趴屏状态继续支持点击与聊天；不会触发站姿撒娇视频。

睡眠场景覆盖原背景，唤醒后恢复之前状态和人物位置。隐藏窗口暂停播放，显示后继续。

## 验证

`benchmarks/quiet-sleep-2026-10-29/modes.json`：13 项状态集成检查通过。检查覆盖模拟闲置、播放器实际跨循环播放、隐藏/显示、点击/聊天唤醒、人物位置恢复；不代表入睡动作已经制作。
