## 文件与加工

- `originals/source-{4,5,6,7}.mp4`：用户原片字节副本，原声、AI 标记和水印保留；原片未覆盖。
- `derived/palm-magic.webm`、`gentle-smile.webm`：专用色键处理后的静音 VP9 alpha，人物边缘仍有轻微残留。
- `derived/moon-room.mp4`、`prayer-scene.mp4`：保留视频编码，去掉音轨；5 的画面元数据保留。
- `manifest.json` 记录原片/派生哈希、尺寸、全帧解码和用途。播放器素材真源另由 `assets/whale-world-web-v1/` 管理。

重做本批派生与 runtime 配置：

```bash
python3 scripts/prepare-world-candidates.py
python3 scripts/prepare-world-video.py
```
